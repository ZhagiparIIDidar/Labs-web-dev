CSS Syntax

Basic CSS Syntax:

selector {
    property: value;
}

Example 1: Element Selector

p {
    color: blue;
    font-size: 14px;
}

Example 2: Class Selector

.highlight {
    background-color: yellow;
    padding: 5px;
}

Example 3: ID Selector

#main-header {
    text-align: center;
    background-color: #333;
    color: white;
}
